TikTok authorization and draft transfer

The production integration connects a creator's TikTok account through Login Kit and transfers an approved video to that creator's TikTok Inbox as a draft. The creator makes the final publishing decision inside TikTok.

Products and scopes

Product or scopeUse in Placebo902 StudioCreator benefit
Login KitOpens TikTok's authorization flow and returns an OAuth code to the desktop application.The creator connects the correct account without sharing a password.
user.info.basicReads the authorized account's basic identity, including open ID, display name, and avatar when available.The dashboard shows which TikTok account is connected and prevents an ambiguous transfer.
Content Posting APIInitializes and transfers an eligible video through TikTok's draft-upload workflow.The prepared file reaches the creator's TikTok Inbox without manual file movement.
video.uploadAllows the video to be uploaded as a draft for further review and editing.The creator retains control of caption, final edits, audience settings, and publication.

Direct Post is not enabled. Placebo902 Studio does not publish directly to the creator's TikTok profile through this integration.

Complete creator flow

  1. The creator opens Channels in Placebo902 Studio and chooses to connect TikTok.
  2. The Studio opens TikTok's official Login Kit authorization page.
  3. The creator signs in to TikTok, reviews the requested permissions, and explicitly authorizes the application.
  4. TikTok redirects the authorization result to the configured desktop callback. The Studio exchanges the one-time code for tokens.
  5. The dashboard uses user.info.basic to identify the connected account to the creator.
  6. After a video passes editorial and technical checks, the creator approves it for transfer.
  7. The Studio uses video.upload to initialize and upload the video to the creator's TikTok Inbox as a draft.
  8. TikTok notifies the creator. The creator reviews or edits the draft, chooses final settings, and decides whether to publish.

Data and token handling

  • Tokens are stored in the creator-controlled local Studio environment, not displayed in the dashboard or public website.
  • Tokens are used only for the TikTok account that completed authorization.
  • The Studio transfers the approved video file and only the metadata needed for the upload operation.
  • The creator can disconnect TikTok in the Studio and revoke access from TikTok's account settings.
  • The Studio does not sell TikTok account information or use it for advertising.

Failure behavior

If authorization expires or TikTok rejects an upload, the candidate is not marked as published. The dashboard reports the disconnected or failed state, keeps the candidate recoverable, and requires valid authorization before another transfer.

Platform review configuration

The production application requests Login Kit, Content Posting API, user.info.basic, and video.upload. The review demonstration uses the TikTok sandbox and shows the actual desktop interface, authorization, connected-account identity, approved draft transfer, and resulting TikTok draft.
