Placebo902 Studio

Aplicación privada de escritorio que ayuda al propietario de la cuenta Placebo902 a preparar videos originales de gaming y transferirlos de forma segura a TikTok como borradores.

Cómo funciona la integración con TikTok

  1. El propietario inicia sesión mediante TikTok Login Kit y autoriza su propia cuenta.
  2. Placebo902 Studio prepara el video, la narración, los subtítulos y los metadatos.
  3. La Content Posting API transfiere el archivo a la bandeja de TikTok como borrador mediante el permiso video.upload.
  4. El propietario revisa, edita y decide si publica el borrador desde la aplicación de TikTok.

Privacidad y control

Placebo902 Studio no publica contenido automáticamente ni ofrece acceso a terceros. Las credenciales y tokens de autorización se almacenan localmente y se utilizan únicamente para la cuenta autorizada por su propietario.
