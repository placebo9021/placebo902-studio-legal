The product

A working production system, not a posting shortcut.

The Studio coordinates each stage of the creator's workflow and records the state of every media item so the next action is observable and recoverable.

01

Media intake

Imports authorized gaming captures, reads technical metadata, detects duplicates, and preserves the original file.

02

Editorial control

Evaluates technical quality, visual suitability, topic repetition, and publication eligibility before a candidate advances.

03

Short-form edit

Builds a vertical version with channel branding and context-aware subtitles while protecting original gameplay visibility.

04

Creator review

Keeps approval, change-request, postponement, and rejection decisions visible in the content queue.

05

Authorized transfer

Uses platform OAuth permissions to transfer only eligible content to the account authorized by its creator.

06

Reconciliation

Checks remote publication state, analytics availability, channel connectivity, storage, and queue health.

Designed for control

The creator stays responsible for the account and the post.

Placebo902 Studio does not request a TikTok password. Login Kit grants limited, revocable OAuth permissions. For draft upload, the creator still opens TikTok, reviews the received draft, edits it if needed, and makes the final publishing decision.
